ClinicaVet: A dedicated application for managing the activities of  a  veterinary clinic, featuring the following core functionalities:

Veterinary Entity and Data Management (JPA): Models and stores specific information in the database, such as patients (pets), their owners, veterinarians, appointments, and offered medical services. 

Web Interface and User Interaction (Web): Provides a web component that facilitates access and navigation for users (pet owners or clinic staff) through a dedicated interface. 

Veterinary Workflow Automation: Manages processes specific to an animal clinic, such as scheduling consultations, maintaining pet records, and handling the relationship between them and the medical staff.
